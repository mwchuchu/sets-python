# Python Sets — Hands-on Lab

A hands-on Python lab covering the fundamentals of **sets in Python**, including set creation, duplicate removal, membership testing, and common set operations.

The complete practical exercises and code implementations are available in the accompanying Jupyter Notebook:

**`PY0101EN-2-3-Sets.ipynb`**

---

## 📌 Overview

Python **sets** are unordered collections of unique elements. They are useful when working with data where duplicate values need to be removed or when comparing and combining collections.

This lab focuses on understanding how sets work and how they can be applied to practical data-processing tasks.

---

## 🎯 Learning Objectives

After completing this lab, you will be able to:

- Create and manipulate Python sets.
- Convert lists into sets.
- Remove duplicate values from collections.
- Add and remove elements from sets.
- Check whether an element exists in a set.
- Perform common set operations.
- Compare sets using subsets and supersets.
- Use sets to identify unique values in data.
